# Frontend

Aplicacion Angular para:

- autenticación,
- listado de usuarios,
- captura de formularios dinámicos,
- gestión administrativa,
- visor de expedientes y adjuntos.

## Módulos sugeridos

- `auth`
- `usuarios`
- `formularios`
- `consentimientos`
- `expedientes`
- `adjuntos`
- `admin-formularios`
- `reportes`
