# Scrum Board Base

## Columnas sugeridas

- `Backlog`
- `Ready`
- `In Progress`
- `Review`
- `Done`

## Epicas

- Plataforma base
- Gestión de usuarios
- Motor de formularios dinámicos
- Consentimientos y expediente
- Adjuntos y MinIO
- Seguridad y auditoría
- Calidad y automatización
- DevOps y observabilidad

## Sprint 0

Objetivo: dejar operativa la base tecnica del monorepo, infraestructura y definicion funcional critica.

## Sprint 1

Objetivo: registro base de usuario, listado y primer formulario dinámico.

## Sprint 2

Objetivo: administracion de formularios, versionado y publicacion.

## Sprint 3

Objetivo: consentimientos, expediente y adjuntos.

## Sprint 4

Objetivo: endurecimiento de calidad, seguridad y pruebas de carga.

## Reglas operativas

- Toda historia debe incluir criterio de aceptacion.
- Los cambios de formulario publicado deben generar nueva versión.
- Ninguna respuesta historica se reescribe contra un schema nuevo.
- Todo adjunto debe vincularse al menos a usuario.
- Todo cambio administrativo relevante debe generar auditoria.
